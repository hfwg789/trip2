# 山河志 · 中国旅行攻略

面向自由行用户的响应式旅行攻略网站，首期收录故宫、长城、兵马俑、西湖、黄山、张家界、九寨沟、漓江、布达拉宫和亚龙湾十个目的地。

## 功能

- 十大景点浏览、关键词搜索和主题筛选
- 统一的景点详情、经典路线、交通、季节、住宿与预算信息
- 浏览器本地收藏和分享链接
- 桌面端、平板端与移动端响应式布局

## 本地预览

站点源码位于 `dist/`，使用任意静态 HTTP 服务打开即可。例如：

```bash
npx serve dist
```

不要直接双击 HTML 文件预览，以免浏览器限制部分功能。

## 内容维护

景点基础数据位于 `dist/data.js`。门票、开放时间、预约和交通属于动态信息，上线前及节假日前应通过景区官方渠道核验。
